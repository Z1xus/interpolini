# Security

interpolini is an offline, client-side app. There's no server or accounts, and the only thing it does over the network is download models and TensorRT when you ask for them in the Components window, so there isn't much to attack,

BUT,

if you do find something real (e.g. a config file or a clip that gets you arbitrary code execution), please don't open a public issue. Report it through [GitHub security advisories](https://github.com/Z1xus/interpolini/security/advisories/new) or contact me directly at [z1x.us](https://z1x.us/), or [hi@z1x.us](mailto:hi@z1x.us) if you prefer email.

Thank you for being responsible.
